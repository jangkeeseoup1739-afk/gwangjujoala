## 1. 사진 바꾸기 (제일 많이 쓰실 기능)

**코드를 건드릴 필요가 없습니다.** `photos` 폴더에 정해진 이름으로 사진을 넣기만 하면 됩니다.

### 휴대폰·PC에서 바꾸는 방법

1. GitHub 저장소에서 **`photos` 폴더**를 엽니다
2. **Add file → Upload files** 를 누릅니다
3. 바꾸고 싶은 사진을 **정해진 파일 이름**으로 바꿔서 올립니다 (예: 거실 사진 → `living.jpg`)
4. **Commit changes** 를 누릅니다
5. **1~2분 뒤 홈페이지에 자동 반영**됩니다

원래 사진으로 되돌리려면 **올렸던 파일을 지우면** 됩니다.

> 확장자는 `.jpg` `.png` `.webp` 아무거나 됩니다. **이름만 맞으면** 됩니다.

### 파일 이름표

전체 목록과 권장 크기는 **[`photos/README.md`](photos/README.md)** 에 정리되어 있습니다. 자주 쓰는 것만 추리면:

| 파일 이름 | 어디가 바뀌는지 |
|---|---|
| `hero.jpg` | 맨 위 대표 배경 (야경) |
| `birdeye.png` | 맨 위 대표 배경 (조감도) · 배치도 섹션 |
| `living.jpg` | 인테리어 갤러리 — 거실 |
| `kitchen.jpg` | 인테리어 갤러리 — 주방 |
| `bedroom.jpg` | 인테리어 갤러리 — 안방 |
| `dressroom.jpg` | 인테리어 갤러리 — 드레스룸 |
| `bathroom.jpg` | 인테리어 갤러리 — 욕실 |
| `lounge.jpg` | 모델하우스 VIP 라운지 |
| `bl1.png` · `bl2-1.png` · `bl2-2.png` | 블럭별 배치도 |

## 2. 상담신청 받기 (처음 한 번만 설정)

고객이 작성한 상담신청을 **구글 스프레드시트로 자동 접수**받고, 신청될 때마다 **메일 알림**을 받을 수 있습니다.
무료이고 건수 제한이 없습니다.

**설정 방법: [`docs/상담신청-받기-설정.md`](docs/상담신청-받기-설정.md)** (5분이면 됩니다)

설정을 마치면 `src/config/form.ts` 의 `endpoint` 한 줄에 주소를 넣는 것으로 끝납니다.

> 아직 설정 전이어도 홈페이지는 정상 동작합니다.
> 고객이 신청 버튼을 누르면 **작성한 내용이 담긴 '문자로 보내기 / 바로 전화하기' 버튼**이 나타나
> 신청이 그냥 사라지지 않습니다.

## 4. 색상 바꾸기

**`src/index.css` 의 `@theme` 부분**만 고치면 홈페이지 전체 색이 함께 바뀝니다.

```css
--color-surface:   #faf8f5;  /* 페이지 바탕 — 웜 아이보리 */
--color-surface-2: #ffffff;  /* 카드 배경 */
--color-ink:       #292524;  /* 본문 글자 */
--color-gold:      #a16207;  /* 골드 글자 */
--color-gold-fill: #fbbf24;  /* 골드 버튼 */
```

> `--color-on-gold` 는 **골드 버튼 위에 올라가는 어두운 글자색**입니다. 이것만은 밝게 바꾸지 마세요 — 버튼 글자가 안 보이게 됩니다.

## 5. 내 컴퓨터에서 실행해 보기

Node.js 설치 후:

```bash
npm install     # 처음 한 번만
npm run dev     # http://localhost:3000 에서 열립니다
```

| 명령어 | 하는 일 |
|---|---|
| `npm run dev` | 개발 서버 실행 (고치면 바로 화면에 반영) |
| `npm run build` | 배포용 파일 생성 (`dist` 폴더) |
| `npm run lint` | 타입 오류 검사 |

## 6. 구성

React 19 + Vite + TypeScript + Tailwind CSS v4

```
photos/                      ← 사진 넣는 폴더 (여기만 쓰시면 됩니다)
src/
  config/consultation.ts     ← 연락처·단지 정보 (한 곳에서 관리)
  config/form.ts             ← 상담신청 접수 주소
  data/projectData.ts        ← 평면도·호재·갤러리 문구
  assets/images/index.ts     ← 사진 연결 (photos 폴더를 자동으로 읽음)
  index.css                  ← 색상 설정
  components/                ← 화면 구성 요소
```

### 화면 구성

맨 위 대표화면 → 사업개요(5개 탭) → 메가 호재 → 주택형 평면도 → 배치도·동호수 →
인테리어 갤러리 → 오시는 길 → 상담 신청 → 하단 정보
(+ 모바일 하단 고정 상담바, VIP 방문예약증)
