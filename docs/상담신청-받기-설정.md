# 상담신청을 구글 스프레드시트로 받기 (5분 설정)

고객이 홈페이지에서 상담신청을 하면 **구글 스프레드시트에 한 줄씩 자동으로 쌓이고, 메일로도 알림**이 옵니다.
무료이고 건수 제한이 없으며, 데이터는 팀장님 구글 계정에 저장됩니다.

---

## 1단계 — 스프레드시트 만들기

1. [sheets.new](https://sheets.new) 에 접속합니다 (구글 로그인 필요)
2. 새 시트가 열리면 왼쪽 위 **"제목 없는 스프레드시트"** 를 눌러
   이름을 **`중앙공원 롯데캐슬 상담신청`** 으로 바꿉니다

> 표의 제목 줄은 만들지 않아도 됩니다. 아래 스크립트가 자동으로 만들어 줍니다.

---

## 2단계 — 스크립트 붙여넣기

1. 그 시트 위쪽 메뉴에서 **확장 프로그램 → Apps Script** 를 누릅니다
2. 새 탭이 열리고 `function myFunction() { }` 같은 내용이 보입니다
3. **그 내용을 전부 지우고**, 아래 내용을 **통째로 복사해서 붙여넣습니다**

```javascript
// 중앙공원 롯데캐슬 시그니처 — 상담신청 수신 스크립트

// 신청이 들어올 때 알림 메일을 받을 주소 (비워 두면 메일을 보내지 않습니다)
var NOTIFY_EMAIL = 'jangkeeseoup1739@gmail.com';

var HEADERS = [
  '신청시각', '성함', '연락처', '관심 주택형',
  '방문희망일', '방문희망시간', '문의내용', '추가 문의사항',
  '담당자', '신청경로', '접수번호'
];

function doPost(e) {
  try {
    var data = JSON.parse(e.postData.contents);
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheets()[0];

    // 첫 줄에 제목이 없으면 만들어 준다
    if (sheet.getLastRow() === 0) {
      sheet.appendRow(HEADERS);
      sheet.getRange(1, 1, 1, HEADERS.length)
           .setFontWeight('bold')
           .setBackground('#faedcd');
      sheet.setFrozenRows(1);
    }

    var now = new Date();
    sheet.appendRow([
      Utilities.formatDate(now, 'Asia/Seoul', 'yyyy-MM-dd HH:mm'),
      data.name || '',
      // 앞의 0이 사라지지 않도록 문자로 저장
      "'" + (data.phone || ''),
      data.unitType || '',
      data.visitDate || '',
      data.visitTime || '',
      data.inquiryTopic || '',
      data.notes || '',
      data.manager || '',
      data.pageUrl || '',
      data.id || ''
    ]);

    if (NOTIFY_EMAIL) {
      MailApp.sendEmail({
        to: NOTIFY_EMAIL,
        subject: '[분양상담 신청] ' + (data.name || '') + ' 고객님 / ' + (data.phone || ''),
        body: [
          '중앙공원 롯데캐슬 시그니처 상담신청이 접수되었습니다.',
          '',
          '성함: ' + (data.name || ''),
          '연락처: ' + (data.phone || ''),
          '관심 주택형: ' + (data.unitType || ''),
          '방문 희망: ' + (data.visitDate || '') + ' ' + (data.visitTime || ''),
          '문의 내용: ' + (data.inquiryTopic || ''),
          '추가 문의사항: ' + (data.notes || '(없음)'),
          '',
          '접수시각: ' + Utilities.formatDate(now, 'Asia/Seoul', 'yyyy-MM-dd HH:mm'),
          '접수번호: ' + (data.id || '')
        ].join('\n')
      });
    }

    return json({ ok: true });
  } catch (err) {
    return json({ ok: false, error: String(err) });
  }
}

function doGet() {
  return json({ ok: true, message: 'consultation endpoint is running' });
}

function json(obj) {
  return ContentService
    .createTextOutput(JSON.stringify(obj))
    .setMimeType(ContentService.MimeType.JSON);
}
```

4. 위쪽 **저장 아이콘(💾)** 을 누릅니다

> 알림 메일을 다른 주소로 받고 싶으시면 맨 윗줄 `NOTIFY_EMAIL` 의 주소만 바꾸세요.
> 메일을 아예 안 받으시려면 `var NOTIFY_EMAIL = '';` 로 비워 두시면 됩니다.

---

## 3단계 — 배포하기 (제일 중요)

1. 오른쪽 위 파란색 **배포 → 새 배포** 를 누릅니다
2. 왼쪽 **⚙️(톱니바퀴) → 웹 앱** 을 선택합니다
3. 아래처럼 맞춥니다

   | 항목 | 선택할 값 |
   |---|---|
   | 설명 | (아무거나, 비워도 됨) |
   | 다음 사용자로 실행 | **나** |
   | 액세스 권한이 있는 사용자 | **모든 사용자** ← 꼭 이걸로! |

4. **배포** 를 누릅니다
5. 권한을 묻는 창이 뜹니다 → **액세스 승인** → 본인 구글 계정 선택
6. **"Google에서 확인하지 않은 앱"** 경고가 나오면
   → 아래 **고급** → **(안전하지 않음) 중앙공원... 으로 이동** 을 누릅니다
   (팀장님이 직접 만든 스크립트라 안전합니다)
7. **허용** 을 누릅니다
8. **웹 앱 URL** 이 나옵니다. `https://script.google.com/macros/s/.../exec` 모양입니다
   → 이 주소를 **복사**합니다

> ⚠️ 3번의 **"액세스 권한이 있는 사용자: 모든 사용자"** 가 핵심입니다.
> 여기가 "나만"으로 되어 있으면 고객의 신청이 들어오지 않습니다.

---

## 4단계 — 홈페이지에 주소 넣기

1. GitHub 저장소에서 **`src/config/form.ts`** 파일을 엽니다
2. 오른쪽 위 **연필 아이콘(✏️)** 을 눌러 편집합니다
3. 이 줄을 찾습니다

   ```ts
   endpoint: '',
   ```

4. 따옴표 안에 복사한 주소를 붙여넣습니다

   ```ts
   endpoint: 'https://script.google.com/macros/s/AKfycb...../exec',
   ```

5. **Commit changes** 를 누릅니다
6. 1~2분 뒤 홈페이지에 반영됩니다

---

## 5단계 — 확인하기

1. 홈페이지의 상담신청 폼에 **본인 이름과 번호로 한 번 신청**해 봅니다
2. 구글 스프레드시트에 줄이 추가되는지 확인합니다
3. 메일이 오는지 확인합니다 (스팸함도 확인해 보세요)

잘 되면 끝입니다.

---

## 잘 안 될 때

| 증상 | 확인할 것 |
|---|---|
| 시트에 안 쌓임 | 3단계에서 **"액세스 권한: 모든 사용자"** 로 했는지 |
| 시트에 안 쌓임 | 4단계 주소가 `/exec` 로 끝나는지 (`/dev` 면 안 됩니다) |
| 메일이 안 옴 | 스팸함 확인 / `NOTIFY_EMAIL` 주소 오타 확인 |
| 연락처 앞 0이 사라짐 | 스크립트가 자동 처리합니다. 그래도 그러면 시트 열 서식을 '텍스트'로 변경 |
| 폼에서 "접수되지 않았습니다" | 4단계 주소를 아직 안 넣었거나 오타. 고객에게는 문자/전화 버튼이 대신 보이므로 신청이 사라지지는 않습니다 |

### 스크립트를 고친 뒤에는

스크립트 내용을 바꾸면 **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포** 를 다시 해야 반영됩니다.
(주소는 그대로 유지되므로 4단계를 다시 할 필요는 없습니다)

---

## 참고 — 주소를 안 넣으면 어떻게 되나요

`endpoint` 가 비어 있어도 홈페이지는 정상 동작합니다.
고객이 신청 버튼을 누르면 **작성한 내용이 그대로 담긴 "문자로 보내기 / 바로 전화하기" 버튼**이 나타나서,
신청 내용이 사라지지 않고 담당자에게 전달됩니다.
