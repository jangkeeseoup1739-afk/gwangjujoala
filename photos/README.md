# 사진 넣는 폴더

이 폴더에 **정해진 이름**으로 사진을 넣으면 홈페이지 사진이 자동으로 바뀝니다.
**코드는 건드리지 않아도 됩니다.**

## 바꾸는 방법 (휴대폰에서도 가능)

1. GitHub 저장소에서 이 `photos` 폴더를 엽니다
2. **Add file → Upload files** 를 누릅니다
3. 바꾸고 싶은 사진을 아래 표의 **파일 이름**으로 바꿔서 올립니다
4. **Commit changes** 를 누릅니다
5. 1~2분 뒤 홈페이지에 자동으로 반영됩니다

사진을 다시 원래대로 돌리고 싶으면 **올린 파일을 지우면** 기본 사진으로 돌아갑니다.

> 확장자는 `.jpg` `.png` `.webp` 아무거나 됩니다. 이름만 맞으면 됩니다.
> (`hero.jpg` 대신 `hero.png` 를 올려도 똑같이 적용됩니다.)

## 사진 준비 팁

- **가로로 긴 사진**이 가장 잘 맞습니다. 세로 사진은 위아래가 잘립니다.
- 한 장당 **2MB 이하**로 줄이면 홈페이지가 훨씬 빠르게 열립니다.
  (휴대폰 사진은 보통 3~5MB라 줄이는 게 좋습니다)
- 사람 얼굴이 크게 나온 사진은 피해 주세요 — 글자가 겹칩니다.
